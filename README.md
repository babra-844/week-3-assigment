# Budget Tracker

## Project Overview

This project is a simple and responsive Budget Tracker designed to help users record and manage their daily expenses.

The application allows users to enter an expense name, amount, category, and date. Added expenses are displayed in a structured table, and the total amount is automatically calculated.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Design and Styling

### 1. Color Palette

The application uses a small and consistent color palette:

- **Navy (#183B56):** Used for headings and table headers.
- **Teal (#2A9D8F):** Used for buttons, accents, and focus states.
- **Light Blue-Gray (#F4F8FA):** Used for the page background and alternating table rows.
- **White (#FFFFFF):** Used for cards, form areas, and table rows.
- **Dark Gray (#263238):** Used for the main body text.

This creates a clean and professional appearance while maintaining good visual consistency throughout the application.

### 2. Typography

Two Google Fonts are used:

- **DM Serif Display:** Used for the main page heading and section headings.
- **Inter:** Used for body text, labels, form controls, buttons, and table content.

The heading font provides a clear visual hierarchy, while Inter keeps the application readable and modern.

### 3. Expense Form

The Add Expense form contains fields for:

- Expense name
- Amount
- Category
- Date

The form inputs use consistent padding, borders, rounded corners, and focus effects. The Add Expense button uses the application's teal accent color.

### 4. Expense Table

The expense table displays:

- Expense name
- Amount
- Category
- Date
- Delete action

The table includes a dark navy header, borders, cell padding, alternating row colors, and a hover effect to improve readability.

### 5. CSS Box Model

The CSS box model is used throughout the project.

- **Margin:** Used to create space between the page heading, form, and expense table.
- **Padding:** Used inside cards, table cells, form controls, and buttons.
- **Border:** Used around cards, inputs, and the table.
- **Border-radius:** Used to give cards, inputs, buttons, and the table a softer modern appearance.

The page heading, Add Expense form, and Expense Table are each displayed as separate card-style sections.

## Features

- Add new expenses.
- Select an expense category.
- Record expense dates.
- Automatically calculate the total expenses.
- Delete individual expenses.
- Responsive layout for smaller screens.
- Styled form and expense table.
- Custom Google Fonts.
- Consistent color palette.

## How to Run

1. Download or clone the project repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Add expenses using the form.

No additional software or dependencies are required.
